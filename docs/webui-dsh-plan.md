# WebUI 对齐 dsh · 设计稿(候批)

参照:/tmp/dsh(DeepSeek Harness client,已读 ui-layout / ui-conversation / ui-subagent / ui-jobs 之行为约定)。
现状截图:/tmp/web_now_empty.png(1400×900,有会话态)。

## 对齐原则(取 dsh 之学,不搬其 React/slot 之形)

1. **回合为节奏单元**:消息流按「轮次」分组,轮间留空;工具/思考折叠为步骤行,展开见全卡。
2. **一切可展开**:步骤行、长消息、压缩检查点、工具树——能收即收,悬念留给一次点击。
3. **灰阶层次**:三级文本色,当前要素 500 字重、附属 400;次级信息 12px;只读信息弱化。
4. **接口静默**:控件只在有用时出现(jobs 钮任务≥1 才渲染;零不宣告零)。
5. **样式只用 token**:色/圆角/阴影全部收敛命名变量,主题切换一处生效。

## 分块设计

### A. Hero 空态(P0)
现状:无会话时正文只有输入框,白地。
目标(dsh `conversation.hero.workspace`):正文中央虚线圆角卡——

```
┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐
│           (piz 鱼标)              │
│     选择一个项目开始对话          │
│   ⌂ pi-zig      ▸ 项目目录 …      │
└ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘
```

- 触发:未选/无当前会话;选项目→连接空白会话,会话壳与输入区不替换(保持 DOM identity)
- 承接「宽屏 748px 优雅利用」:Hero 期检视栏不出现,单栏居中

### B. 轮次分组 + 步骤摘要流(P0)
现状:消息平铺,工具卡与文本混排,轮次无边界。
目标:

```
12:40  hi                      (用户,灰 12px 时间戳)
▸ search · 0.4s  ✓            (步骤行:名称+耗时+状态)
▸ command  ✓
  Hello! This looks like…     (助手文本,定稿块)
  ┊ 正在生成…                 (流式尾部隔离段,与定稿分块)
```

- 步骤行:圆角 8px、灰底三级;点击展开整卡(输出/元数据);支持嵌套缩进
- 轮次状态:流式中步骤行左侧动符,完成转 ✓;轮间 24px
- 用户消息 >6 行折叠为一行,点击展开
- 数据前提:后端事件流需按 turn 边界分组(emitTurnEnd 已存在);工具卡属性(耗时/状态/嵌套)已齐

### C. 压缩检查点行(P1)
现状:compact 只一行 notice 即焚。
目标(dsh checkpoint row):

```
⧉ 上下文已压缩 · 折叠 87 条 · 省 ~54k tok   [展开 ▸]
```

- 渲染在消息流中自己的位置,不替换上方 transcript;悬停/聚焦才显示展开图标;自动压缩用「上下文已压缩」标题,手动 /compact 运行中是活动行、结算后折叠进同一检查点
- 展开见摘要文本(12px 灰)

### D. 会话头对齐(P1)
现状:顶栏一行(⌂ 面包屑 ⋯),无谱系。
目标(dsh session.header):

```
⌂ pi-zig / 默认会话  main   [✎]        ●3  ⠿(3)  ⋯
     (workspace 面包屑)  (标题,可重命名)   (谱系) (jobs)(菜单)
```

- subagent 谱系面包屑:当前 title 500 字重主色,祖先 400 三级色;带 `/ 3` 后代数量下拉,12px;悬停 150ms 开目录,键盘 ↓ 入口;祖先点击只向上导航
- jobs 弹层对齐(已有):排序=活跃 finishedAt… 活跃 startedAt 升序在前、终态 finishedAt 降序;终态行弱化保留(失败 detail 可读);耗时冻结、活跃每秒推进;Esc 焦点还触发器
- 数据前提:需要 subagent 谱系接口(列表已可从 activity 取;父子关系后端补 lineage 字段)

### E. 工具树(P1)
现状:单层卡片。
目标(dsh ui-tool 树):

```
▸ bash · 12s · ok
  ├─ read src/main.zig · 8ms
  └─ bash zig build · 12s
     └─ (输出块折叠)
```

- 父子 16px 缩进 + 连接线;叶子无箭头;同层按调用序;状态徽章 ok/running/err
- 键盘:←→ 折叠展开,↑↓ 导航,Enter 展开

### F. 输入区 dock(P1)
现状:composer 卡含 pills/成本/ctx 环,一律悬浮。
目标(dsh editor dock + input dock):

```
┌ 计划条:● 1 ● 2 ● 3 (todo,可折叠) ────────────┐
├ 队列行(待发 N) ──────────────────────────────┤
├ 编辑器卡 [textarea] ─────────────────────────┤
└ 统计行:12.3k/64k · $0.042 · 3 任务  [➤]      ┘
```

- 统计行与输入区同 dock sticky;内联触发:`/` 命令(已有)、`@` 弹「运行中子代理 / @file / @session」候选、插入字面 `@label`
- 模型 pill:选中即示一行描述(可选增强)

### G. 主题 token 化(P0 底子)
- 收敛 `--bg-1/2/3 --tx-1/2/3 --line --acc --r-8/12 --sh-1`;html color-scheme 已有;meta theme-color 随 body 背景计算跟随(dsh theme renderer 同法)

### H. 侧栏微调(P2)
- subagent origin 会话行 ↳ 缩进弱化(不省略——piz 侧栏是唯一会话入口,与 dsh 不同取舍)
- 侧栏宽可拖(拖柄,记忆于 localStorage)

## 分期

- **P1**(二轮):C 检查点 + D 会话头谱系/jobs 对齐 + F 输入区
- **P2**(三轮):E 工具树 + H 侧栏
